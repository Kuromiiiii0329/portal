## 五、口径说明

- **评分** = `|IC| × min(1, |IR| / 0.30) × 覆盖率`，与讨论循环的回溯判断同一口径。
- **入库门槛**：`|IC| ≥ 0.02`、`|IR| ≥ 0.20`、`覆盖率 ≥ 50%`，且不得含涨停/追高语义、不得与已有因子重复。
- **IC**：因子值与次日收益的截面秩相关；**IR**：IC 均值 / 标准差。
- **出现次数**：该因子在各历史预案候选的 `setup` 里被记录的次数。
